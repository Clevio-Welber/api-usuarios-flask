# API REST de Usuários

API REST desenvolvida em **Python** utilizando o framework **Flask**, com o objetivo de disponibilizar operações para gerenciamento de usuários através de requisições HTTP.

## 🚀 Tecnologias

* Python
* Flask
* API REST
* JSON
* Git e GitHub

## Estrutura do projeto

text
api-usuarios-flask/
├── data/
├── app.py
├── user.pu
├── user_controller.py
├── users.py
└── README.md

## Como executar o projeto

### 1. Clonar o repositório

bash
git clone https://github.com/Clevio-Welber/api-usuarios-flask.git
cd api-usuarios-flask

### 2. Criar um ambiente virtual

Linux/macOS:

bash
python3 -m venv .venv

Windows:

bash
python -m venv .venv
